# R Shiny 临床数据交互模板

这套程序包含 5 个独立模板和一个统一入口。默认打开完全模拟数据，不读取现有临床项目，不依赖现有 TFL 的 setup。

## 1. 最快开始

1. 双击 `Shiny临床模板.Rproj`，在 RStudio 中打开这个文件夹。
2. 初次使用运行 `install_packages.R`。当前电脑已安装测试所需依赖；换电脑或 R 主次版本后可重新运行。
3. 打开 `start.R`，点击 **Source**，即可一起打开五个模板。
4. 也可以分别运行 `run_01_risk_matrix.R`、`run_02_event_counts.R`、`run_03_longitudinal.R`、`run_04_query_tracking.R`、`run_05_graphs.R`。
5. 先用模拟数据体验。换数据时，在左侧选“导入我的数据”，选择文件，再从下拉框中映射实际变量名。修改立即反映到图表中。
6. 点击“保存变量映射”下载 JSON；以后先导入新数据，再恢复 JSON，核对变量及筛选取值即可。JSON 保存映射和设置，不保存原始数据。

`config_examples` 中另有一份字段名改为 Center/RiskName/Observed 的 CSV 和对应 JSON，可用于练习“先导入，再恢复映射”。`preview` 中有界面截图。

标准 Shiny 启动方式也适用：

```r
shiny::runApp("这个模板文件夹的完整路径", host = "127.0.0.1")
```

运行期间 R 控制台会被 Shiny 占用，这是正常现象。点击 RStudio 的 Stop 停止服务。程序仅监听本机 `127.0.0.1`，不会自动部署或上传到外部服务器。

## 2. 五个模板分别处理什么

| 入口 | 输入数据 | 变量映射 | 输出及交互 |
|---|---|---|---|
| 01 KRI 风险矩阵 | 已汇总的 KRI 长表 | 站点、指标名、数值，可选日期和分母 | 风险等级堆积柱状图、阈值比较散点图、红黄绿矩阵、指标趋势、汇总明细 |
| 02 事件计数与钻取 | 受试者分母表 + 事件表 | 两表的受试者 ID、分组、可选分类及筛选标志 | 去重人数 n、记录数 C、分母 DEN、比例及 Wilson 95% CI、事件原记录钻取 |
| 03 连续指标趋势 | 带访视或日期的长表 | 分组、时间、分析值，可选 ID、访视排序号和指标 | 均值及 95% t CI、中位数及 Q1/Q3、个体轨迹、组别筛选、统计明细 |
| 04 Query 追踪 | 每条 Query 一行的生命周期表 | 站点、Query ID、开启/关闭日期，可选受试者 ID | 未关闭数、逾期数/比例、年龄、历史积压趋势、站点钻取及仅看逾期 |
| 05 通用图形 | 任意结构合适的数据框 | 按图形选择数值、分类、分组及筛选变量 | 箱线图、小提琴图、直方图、散点图、分类柱状图、缺失率图；支持悬停、缩放和 PNG 下载 |

适用范围由数据结构决定。相同结构可映射到其他项目：事件计数可用于 AE 或方案违背；连续趋势可用于实验室、生命体征或疗效指标。变量名称可以不同，统计单位和规则仍需明确。

## 3. 模板 01：KRI 风险矩阵

输入必须是 **站点 × 指标 × 快照日期唯一** 的汇总长表，而不是原始 ADSL/ADAE。没有日期也可使用，只展示一次快照。

示例结构：

| CENTER | INDICATOR | OBSERVED | ASOF | N |
|---|---|---:|---|---:|
| A01 | AE例次/100人 | 80 | 2026-11-24 | 30 |
| A01 | Query逾期率(%) | 20 | 2026-11-24 | 10 |
| A02 | AE例次/100人 | 15 | 2026-11-24 | 25 |

对应选择：站点 = CENTER，指标 = INDICATOR，数值 = OBSERVED，日期 = ASOF，分母 = N。

- VALUE 按原单位展示，不会自动把 0.2 转换成 20%。输入是百分比还是比例，必须与阈值使用同一单位。
- 双击阈值表修改数字，按 Tab 或点击其他位置保存。下限采用 `<=`，上限采用 `>=`；红色优先于黄色。
- 可只设置上限或下限，也可设置双侧边界。空白表示不使用该边界。
- 最小分母为 0 时不限制样本量；大于 0 时，需要提供分母且达到该数值。否则为灰色“未评估”。没有任何边界、数值缺失也为灰色。
- 自定义指标初始没有阈值；先设置后才会得到红黄绿分级，避免替你猜测临床边界。
- 点击矩阵单元格，将当前站点和指标带入趋势。下方明细是输入的 KRI 汇总记录，不会凭空生成受试者源记录。
- 站点风险分布图按红、黄、绿和未评估统计指标数量，不将不同量纲的 KRI 数值相加。单项 KRI 比较图按站点实测值排序，并标出所设阈值线；不是统计学漏斗图。
- 事件计数和 Query 模板都能“导出为模板 01 的 KRI 长表”，可把计算结果接入矩阵。

## 4. 模板 02：分母、人数和例次

分母表应每名受试者一行。受试者 ID 必须能唯一标识一个人，不能用只在单一站点内唯一的序号直接连接所有站点。

1. 在分母表选择 ID、分组变量，例如 SITEID 或 TRT01P。
2. 可选一个筛选标志，例如 SAFFL，再选择纳入的取值，例如 Y。
3. 在事件表选择对应 ID；可选分类变量，例如 AEDECOD。分类不选时统计全部事件。
4. 可选一个事件筛选标志及其取值，例如 AESER=Y；复杂筛选可在输入数据中先派生一个分析标志，再映射该标志。

统计口径：

```text
DEN = 分母表中该组受试者人数
C   = 匹配该人群、满足事件筛选条件的事件记录数
N   = 这些事件记录中的去重受试者人数
PCT = N / DEN × 100
```

- 分母来自人口表，不会从“发生了事件的人”推算。没有事件的组也保留并显示 0。
- 一个受试者在同一分类发生多次，例数只计一次，例次保留全部记录。
- 合计组独立计算，不将各分类或各组的人数盲目相加。
- 图上的置信区间是受试者发生比例的 Wilson 95% 区间，不是例次的区间。
- 事件日期不在本模板中自动限制，结果快照日期只写入导出文件，不筛选记录。若分析截至某天或特定窗口，请在输入数据/分析标志中先限定。
- 此处是“发生受试者百分比”，不是按人年/暴露时长计算的 AE 发生密度；后者需要另行定义暴露分母。
- 选中结果表一行，下方显示其事件原记录和对应分析组别。

## 5. 模板 03：连续指标与访视

- “横轴类型”选访视时，建议同时映射 AVISITN 等排序号；不选排序号时按输入中首次出现的访视顺序展示，不自动按字母排序。
- “横轴类型”选日期时，映射真实日期变量；日期解释见下节。
- 指标变量可用于 PARAMCD/PARAM。界面每次选择一个指标，避免把不同单位的指标混在同一数值轴。
- 映射了受试者 ID 时，要求同人×组别×时间点一条记录。若出现重复，默认提示先整理；也可明确选择“先取均值”。
- 没有受试者 ID 时，可以按记录汇总，但无法生成可信的受试者个体轨迹。
- n 是非缺失观测数；MISSING 是输入中已有记录的分析值缺失数。若某受试者整个访视没有记录，本工具不会自动补出计划访视，也不会把它计作缺失。
- 均值区间采用 `mean ± qt(0.975,n-1) × SD/sqrt(n)`；n<2 时不计算区间。中位数图的上下界是 Q1/Q3，分位数算法明确采用 `type=2`。
- 本模板只做观察数据的描述，不插补，不调整基线，不替代 MMRM/重复测量模型。跨访视的图不代表模型调整后的治疗效应。
- 个体轨迹按编号排序后截取设定人数，避免一次绘制大量线条；这不是随机抽样。

## 6. 模板 04：Query 年龄与历史快照

Query ID 必须唯一，一行包含开启日期和最终关闭日期；尚未关闭的关闭日期填 NA/空白。

```text
快照时未关闭 = 开启日期 <= 快照日，且关闭日期缺失或晚于快照日
未关闭年龄   = 快照日 - 开启日期
已关闭年龄   = 关闭日期 - 开启日期
逾期         = 快照时未关闭，并且年龄 > 设定天数
逾期比例     = 逾期且未关闭数 / 未关闭数 × 100
```

关闭日期恰等于快照日时视为已关闭，快照日之后才开启的 Query 不纳入。未关闭数为零时，逾期比例为缺失而不是 0%。

这套生命周期输入无法表达反复开启/重开/再次关闭的完整状态历史。存在重开时，应先按选定快照整理状态，或扩展为状态事件流模型，不能直接删掉重复 Query ID。

## 7. 模板 05：通用图形

独立运行 `run_05_graphs.R` 或在统一入口点击“05 通用图形”。默认数据为 `demo_data/graphs.csv` 对应的模拟基线数据，包含 AGE、FVCEFF、ALT 和组别。

| 图形 | 需要选择的变量 | 示例 |
|---|---|---|
| 箱线图、小提琴图 | 分析值，分组可选 | 按治疗组比较 FVCEFF 分布 |
| 直方图 | 分析值，分组可选 | 查看年龄或实验室指标的分布 |
| 散点图 | X、Y 两个数值变量，分组可选 | 年龄与 FVC% 的关系 |
| 分类柱状图 | 分类变量，分组可选 | 按站点比较记录数，或按 ID 统计去重人数 |
| 缺失率图 | 一个或多个待检查变量 | 对比各列的缺失比例 |

可选任何额外的筛选变量，例如 SAFFL，再选择 Y；对长表可先按 PARAMCD 选择同一指标。连续图按记录绘制，不对重复受试者自动汇总，实际分析时应按分析单位先整理数据。分类柱状图勾选去重人数后，按每组每类别的非缺失 ID 去重。缺失率以当前筛选后的记录数为分母。CSV 读取时常规空白会先解析为 NA；如果源数据保留了空字符串，可用界面开关控制是否将其计为缺失。

图形可缩放、悬停查看值、点击图例隐藏/显示组别，并用图形工具栏的相机按钮导出 PNG。下方可下载当前汇总数值或散点数据；汇总表分位数采用 R type=2，箱线图和小提琴图内的箱体采用 Plotly 绘图算法，可能与汇总表四分位数略有差别。

## 8. 文件与日期

- 支持 CSV、Excel、SAS7BDAT、XPT，以及内容为数据框的 RDS。
- CSV 默认按字符读取，保护 001 等带前导零的编号。被映射为数值的列再严格转换，不把“无法转换”的内容默默当作 NA。
- CSV 可切换 UTF-8 或 GB18030；Excel 可填写工作表名称或序号。
- haven 读到的 Date 日期和 Excel 日期对象直接使用。
- 字符日期需要填写格式，如 `%Y-%m-%d`、`%Y/%m/%d` 或 `%d%b%Y`。
- 裸数值日期需要选择起点：SAS 1960-01-01、R 1970-01-01、Excel 1899-12-30。只有数值真正代表“距该起点的天数”时才可如此解释。
- 数值 20261124 不等于 SAS 日期，须先作为字符并用 `%Y%m%d` 解释。时间戳、部分日期等应先按项目规范处理。
- 导出 CSV 使用 UTF-8 BOM，便于 Windows Excel 打开。统计导出保留数值；界面的舍入不改写计算结果。

## 9. 程序结构

```text
app.R                         标准 Shiny 入口
start.R                       一次启动五个模板，可 Source
run_01_...R 至 run_05_...R     各模板单独启动
install_packages.R            依赖安装，正常启动不联网安装
R/bootstrap.R                 查找专用包库、加载文件
R/data_tools.R                读写、映射、日期和公共界面工具
R/analysis_tools.R            计数、比例区间、趋势汇总、Query 快照等小工具
R/template_*.R                各模板独立 UI 与 server 模块
R/dashboard.R                 组合五个模块
R/demo_data.R                 可复现模拟数据生成
demo_data/                    同一批 CSV 与 RDS 示例
tested_package_versions.csv   本次试跑版本记录
```

每个会话单独保存自己的数据和阈值，不把用户上传的数据写入共享全局对象。程序没有用户管理、权限控制、持久化审计轨迹或在线部署功能。

## 10. 与 gsm / 正式中心化监察的关系

本套是通用变量映射和可视化模板，使用 Shiny、bslib、DT、plotly、haven、readxl、readr、dplyr、tidyr、jsonlite。这里没有调用 gsm 的统计异常检测，也不把手动阈值标记说成经模型校准的告警；没有计算 KRI 异常检验的 P 值。

正式 KRI 的分母、分析窗口、小站点处理、多次查看/多指标及阈值解释，应与监查计划一致。QTL 是研究级质量管理概念，不等同于给每个站点的单元格设一个红色边界。

“非递交”或“用 Shiny 开发”本身不决定验证要求。若工具用于实际试验监察决策，应按预定用途落实相应的系统及统计验证。本模板不声称已经完成该类验证。
